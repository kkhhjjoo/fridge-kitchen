# 디자인: 냉털 요리 도우미

> 기존 웹사이트 **냉털키친**의 디자인(색, 글꼴, 버튼, 카드 모양)을 그대로 가져와 쓴다.
> 기준 파일: tailwindcss로 한다.
> 화면 내용과 기능은 [PRD.md](PRD.md)를 따른다.

## 1. 전체 느낌

- **차분한 초록**(채소, 허브 느낌) + **따뜻한 아이보리 배경** + **오렌지 포인트**
- 글자는 순수 검정 대신 따뜻한 짙은 갈색-회색을 쓴다.
- 모서리는 둥글게, 그림자는 은은하게 → 부엌 메모장처럼 편안한 느낌

## 3. 글꼴과 글자 크기

- 글꼴: **Pretendard** (없으면 Apple SD Gothic Neo, Noto Sans KR)
- 한글 단어가 줄 끝에서 중간에 끊기지 않게 한다.

| 쓰임                       | 크기               | 굵기              |
| -------------------------- | ------------------ | ----------------- |
| 화면 제목                  | 30px (휴대폰 24px) | 굵게              |
| 묶음 제목 ("재료 넣기" 등) | 20px (휴대폰 18px) | 굵게              |
| 요리 이름                  | 16px               | 굵게              |
| 본문, 입력칸               | 15px               | 보통              |
| 설명, 보조 글              | 14px               | 보통, 연한 글자색 |
| 표시(배지)                 | 12px               | 약간 굵게         |

## 4. 모양

- **카드:** 흰 배경, 모서리 20px 둥글게, 은은한 그림자. 마우스를 올리면 그림자가 조금 진해진다.
- **입력칸:** 높이 44px, 모서리 12px, 아이보리 테두리. 누르면 테두리가 초록으로 바뀌고 연한 초록 빛이 둘러진다.
- **버튼:** 알약 모양(완전히 둥근 끝), 높이 44px 이상(휴대폰에서 누르기 쉽게).
- **표시(배지):** 알약 모양, 작은 글자.

## 5. 버튼 종류

| 종류   | 모양                      | 쓰는 곳                                               |
| ------ | ------------------------- | ----------------------------------------------------- |
| 포인트 | 오렌지 배경 + 흰 글자     | **요리 추천받기** (화면에서 가장 중요한 버튼, 하나만) |
| 기본   | 초록 배경 + 흰 글자       | 추가, 장보기 목록 만들기, 복사, 로그인                |
| 보조   | 흰 배경 + 아이보리 테두리 | 저장, 다시 시도, 로그아웃                             |
| 글자만 | 배경 없음                 | 태그의 ×, 접기/펼치기                                 |

- 누를 수 없을 때(재료 0개 등)는 흐리게(투명도 50%) 보이고 눌리지 않는다.

## 6. 화면 구성 (위에서 아래로, 한 장)

화면 가운데에 최대 너비 **720px**로 놓는다. 묶음 사이 간격은 넉넉하게(약 40px) 둔다.

### 6-0. 맨 위 줄

- 왼쪽: 로고 — 초록 네모 안에 냉장고 그림 + "냉털 **요리 도우미**" ("냉털"은 진한 글자색, "요리 도우미"는 초록)
- 오른쪽: 로그인한 이메일(연한 글자) + 로그아웃 버튼(보조)
- 스크롤해도 위에 붙어 있고, 뒤가 은은하게 비친다.

### 6-1. 로그인 화면 (로그인 안 했을 때만, 이것만 보임)

- 가운데 흰 카드 하나: 로고 → "이메일로 로그인" 제목 → 이메일 입력칸 → 비밀번호 입력칸 → 로그인 버튼(기본, 카드 너비 가득)
- 틀리면 입력칸 아래에 빨간 작은 글씨로 이유를 보여 준다.

### 6-2. 재료 넣기

- 묶음 제목: **내 냉장고 재료**
- 입력칸(안내 글: `계란, 국수, 간장처럼 쉼표로 적어도 돼요`) + 오른쪽에 **추가** 버튼(기본)
- 아래에 재료 **태그**가 줄줄이 쌓인다.
  - 태그 모양: 흰 배경 알약 + 아이보리 테두리, 글자 옆에 작은 **×**
  - 재료가 없으면 점선 상자에 "아직 넣은 재료가 없어요" (연한 글자)
- 그 아래 **요리 추천받기** 버튼(포인트, 크게, 너비 가득)

### 6-3. 추천 요리 5개

- 묶음 제목: **추천 요리** / 설명: "겹치는 재료가 많은 순서예요"
- 요리 카드 5장을 세로로 쌓는다. (넓은 화면에서는 2줄로 놓아도 된다)
- **요리 카드 (접힌 상태)**
  - 요리 이름(굵게) + 오른쪽에 표시
    - 목록에 있던 요리: 초록 연한 배지 "재료 3개 있음"
    - AI가 만든 요리: **오렌지 배지 "✨ AI 추천"**
  - 한 줄 설명(연한 글자)
  - 아래 작은 글씨: 🕒 10분 · 더 필요한 재료 2개 (오렌지) / 또는 ✓ 바로 만들 수 있어요 (초록)
- **요리 카드 (눌러서 펼친 상태)** — 카드가 아래로 늘어난다
  - 🕒 걸리는 시간
  - **있는 재료:** 초록 연한 배지들
  - **더 필요한 재료:** 오렌지 연한 배지들
  - **만드는 순서:** 번호 동그라미(초록 배경, 흰 숫자) + 단계 설명, 단계마다 줄을 띄운다
  - 맨 아래 버튼 두 개: **장보기 목록 만들기**(기본) · **저장**(보조, ♡ 그림)
  - 한 번에 한 카드만 펼친다.

### 6-4. 장보기 목록

- 묶음 제목: **장보기 목록 · {요리 이름}**
- 흰 카드 안에 체크리스트: 네모 체크칸 + 재료 이름. 체크하면 글자에 줄이 그어지고 흐려진다.
- 카드 오른쪽 위에 **복사** 버튼(기본, 📋 그림)
- 더 필요한 재료가 없으면 초록 연한 상자에 "✓ 장 볼 것 없이 바로 만들 수 있어요"

### 6-5. 저장된 기록

- 묶음 제목: **저장한 요리**
- 한 줄짜리 흰 카드 목록(최근 것이 맨 위): 요리 이름 · 🕒 시간 · AI 추천이면 오렌지 배지
- 누르면 6-3과 같은 모양으로 펼쳐진다.
- 없으면 점선 상자에 "♡ 마음에 드는 요리를 저장해 보세요"

## 7. 상태별 모양

| 상태        | 모양                                                                                                |
| ----------- | --------------------------------------------------------------------------------------------------- |
| 불러오는 중 | 요리 카드 자리에 아이보리색 회색 상자가 천천히 깜빡인다 (카드 5장 모양). 버튼 글자는 "추천받는 중…" |
| 실패        | 점선 상자 + "요리를 불러오지 못했어요" + **다시 시도** 버튼(보조)                                   |
| 빈 상태     | 점선 상자 + 연한 글자 + 다음에 할 일 안내                                                           |
| 알림        | 화면 아래 가운데에 둥근 알림이 4초 동안 뜬다. 성공은 초록("복사했어요", "저장했어요"), 실패는 빨강  |

## 8. 휴대폰 화면

- 좌우 여백 16px, 넓은 화면에서는 24px
- 입력칸과 추가 버튼은 한 줄을 유지하고, 다른 버튼은 너비를 가득 채운다.
- 요리 카드는 한 줄에 하나씩

## 9. 쓰기 편하게 (접근성)

- 키보드 Tab으로 이동할 때 초록 테두리가 보인다.
- 색만으로 뜻을 전하지 않는다. "AI 추천", "더 필요한 재료"처럼 늘 글자를 함께 쓴다.
- 그림만 있는 버튼(태그의 ×)은 "계란 지우기"처럼 무엇을 하는지 읽어 준다.
- 움직임 줄이기를 설정한 사람에게는 깜빡임, 움직임을 거의 없앤다.
